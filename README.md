# Meu Corpo Meu Espaço

Crie uma landing page de vendas em português para o produto digital “Roda de Conversa: Meu Corpo é Meu”. Use todo o conteúdo fornecido pelo usuário: hero com headline contendo countdown vermelho, mockup ilustrativo do PDF e cartas, seções de dores, apresentação, itens recebidos, público, 5 depoimentos, 3 bônus, dois planos com Kit Completo dominante e badge “Mais escolhido”, garantia de 7 dias, FAQ, CTA final, popup de saída e popup de upsell pós-compra. Visual premium, acolhedor e educativo, sem estética infantil genérica: azul petróleo, azul claro, creme/off-white, amarelo suave e verde suave; fonte Inter; botões grandes mobile-friendly (mín. 52px). Garanta navegação suave dos CTAs para a oferta e responsividade impecável. O countdown deve ser vermelho e funcional, com urgência moderada, na área da headline.
